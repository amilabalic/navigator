# navigator - Cypress E2E Testing Project

This project uses Cypress and JavaScript to perform end-to-end (E2E) testing for a web application called "Navigator".
All tests were written and executed in Visual Studio Code, and test case documentation is managed in Qase.io.

_Features_

-Smoke test for search functionality
-5 test cases covering menu content list
-3 test cases for feedback functionality
-Tests written and automated using Cypress
-Runs tests using specifically Google Chrome v135

_Tech Stack_

-Cypress
-Javascript
-VS Code
-Qase.io for test case management

_Installation_

1. Clone the repository

   ```bash
   git clone <your-repo-url>
   cd navigator

   ```

2. Install dependencies:
   npm install

3. Ensure Cypress is installed:
   npm install cypress

Make sure you are using Google Chrome v135 for accurate test execution.

_Running Tests_

1. Open Cypress Test Runner
   npx cypress open

2. Select E2E Testing
3. Choose Google Chrome v135

_Test Management_

All test cases for this project are documented in Qase.io:
-Smoke test: Search functionality
-Functional tests:
-Header Testing (6 cases + 1 bug report)
-Menu content list (8 cases)
-Feedback functionality (3 cases)
-"Kreiraj objekat" functionality (2 cases + 1 bug report)
-"Predloži ideju - Pošalji komentar" functionality (3 cases + 1 bug report)
