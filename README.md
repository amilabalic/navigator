# navigator - Cypress E2E Testing Project

This project uses Cypress and JavaScript to perform end-to-end (E2E) testing for a web application called "Navigator".
All tests were written and executed in Visual Studio Code, and test case documentation is managed in Qase.io.

_Features_

1. Smoke test for search functionality
2. 5 test cases covering menu content list
3. 3 test cases for feedback functionality
4. Tests written and automated using Cypress
5. Runs tests using specifically Google Chrome v135

_Tech Stack_

1. Cypress
2. Javascript
3. VS Code
4. Qase.io for test case management

_Installation_

1. Clone the repository

   ```bash
   git clone <your-repo-url>
   cd navigator

   ```

2. Install dependencies:
   npm install

3. Ensure Cypress is installed:
   npm install cypress

Make sure you are using Google Chrome v135 for accurate test execution.

_Running Tests_

1. Open Cypress Test Runner
   npx cypress open

2. Select E2E Testing
3. Choose Google Chrome v135

_Test Management_

All test cases for this project are documented in Qase.io:

1. Smoke test: Search functionality
2. Functional tests:
3. Header Testing (6 cases + 1 bug report)
4. Menu content list (8 cases)
5. Feedback functionality (3 cases)
6. "Kreiraj objekat" functionality (2 cases + 1 bug report)
7. "Predloži ideju - Pošalji komentar" functionality (3 cases + 1 bug report)
